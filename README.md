# 領地経営カードゲーム / Analog Game Prototype

領地経営・産業発展をテーマにした、2〜5人用カードゲームの試作実装です。  
現在はブラウザ上で動くプロトタイプとして実装しています。

## 現在の目的

アナログゲームとして成立するルール・テンポ・得点設計を検証するための試作です。  
デジタル実装は、主に以下を確認するために使います。

- ターン進行の確認
- 資源・需要・固定役のバランス確認
- CPU挙動の試験
- UI上での分かりやすさ確認
- 仕様変更時の影響確認

## 起動方法

`index.html` をブラウザで開くことで起動できます。

## 主なファイル構成

```text
index.html              画面構造
style.css               見た目
src/main.js             起動処理・イベント接続
src/game.js             ゲーム状態・ターン進行
src/actions.js          プレイヤー行動の処理
src/data.js             資源・特産品・需要・固定役データ
src/ui.js               画面描画
src/cpu.js              CPU行動
src/logger.js           ログ管理
