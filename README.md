# 領地経営カードゲーム / Analog Game Prototype

領地経営・産業発展をテーマにした、2〜5人用カードゲームの試作実装です。  
現在はブラウザ上で動くプロトタイプとして実装しています。

## 現在の目的

アナログゲームとして成立するルール・テンポ・得点設計を検証するための試作です。  
デジタル実装は、主に以下を確認するために使います。

- ターン進行の確認
- 資源・需要・固定役のバランス確認
- CPU挙動の試験
- UI上での分かりやすさ確認
- 仕様変更時の影響確認

## 起動方法

ローカルサーバー経由で `index.html` を開く方法を推奨します。
このプロジェクトはブラウザの ES Modules を使っているため、ブラウザや設定によっては `file://` で直接開くと `src/*.js` の読み込みが失敗する場合があります。

### VS Code を使う場合

VS Code 拡張機能の **Live Server** を使います。導入済みであれば追加作業は不要です。

1. VS Code でこのフォルダを開く。
2. `index.html` を開く。
3. 右下の `Go Live` を押す。
4. 表示された `http://127.0.0.1:xxxx/` または `http://localhost:xxxx/` でゲームを起動する。

### コマンドで起動する場合

Python が入っている環境では、プロジェクトルートで以下を実行します。

```powershell
python -m http.server 8000
```

その後、ブラウザで `http://127.0.0.1:8000/index.html` を開きます。

## 文字コード

このリポジトリのテキストファイルは UTF-8 で統一します。VS Code ではワークスペース設定 `.vscode/settings.json` で `files.encoding` を `utf8` にしています。

要件ファイルが文字化けして見える場合は、VS Code 右下の文字コード表示から `Reopen with Encoding` → `UTF-8` を選んで開き直してください。正しく表示されたら、必要に応じて `Save with Encoding` → `UTF-8` で保存します。

Windows PowerShell 5.1 では、既定の読み込みが UTF-8 にならず文字化けすることがあります。コマンドで確認するときは以下のように `-Encoding UTF8` を明示してください。

```powershell
Get-Content -Encoding UTF8 -LiteralPath 'テスト版要件V0.2.2.txt'
```

## 検証方法

現在は自動テストを用意していないため、ブラウザ上での手動検証を基本とします。
確認時はブラウザの開発者ツールを開き、Console に赤いエラーが出ていないことも確認してください。

### 初期セットアップの確認

1. ゲームを起動する。
2. 人間 `1`、CPU `0` でゲーム開始する。
3. 盤面はまだ表示されず、初期特産品5枚から稼働させる3枚を選ぶ画面だけが表示されることを確認する。
4. 3枚を選択して決定する。
5. 決定後に盤面が表示され、中央マーケット4枚、需要カード6枚、選択済みの稼働特産品3枚、未開発特産品2枚が見えることを確認する。
6. 初回生産後、稼働特産品3枚に対応する資源が手札に入っていることを確認する。

### CPU を含むスモークテスト

1. 人間 `1`、CPU `1` でゲーム開始する。
2. 人間の初期特産品を3枚選んで決定する。
3. CPUの初期セットアップが自動で進み、盤面表示とゲーム本編に進むことを確認する。
4. 数ターン進めて、マーケット交換、需要達成、固定役達成、ターン終了で致命的なエラーが出ないことを確認する。
